Public sports reference prices refresh only after an archived row matches the exact card identity and has a numeric PriceCharting product ID. The shared `pricecharting-global-v1` instance of `CardReferenceArchive` caches a verified result for 24 hours. A page request returns the saved estimate immediately and queues a stale ID; a Durable Object alarm performs the lookup later. This does not enumerate the catalog or collect photos.

The same object handles existing staff API lookups. Its persistent gate spaces upstream starts by 1.1 seconds, including failures and concurrent visitors. Repeated staff lookups also share a five-minute response cache. Tokens travel only through private Worker bindings; provider failures return sanitized errors. Missing bindings fail closed. Quota/auth failures pause upstream work for an hour, other outages for a minute, retaining queued demand and previous verified prices.

Product ID, product name and console must match before public prices change. Integer cents map to ungraded (`loose-price`), grade 9 (`graded-price`) and PSA 10 (`manual-only-price`). Empty prices and failed identity checks preserve the prior estimate and its capture timestamp. A capture date appears beside displayed estimates. Photos, holds and duplicate checks are unchanged.

`reference-price-refresh.test.mjs` tests demand deduplication, freshness, real concurrent spacing, shared staff/public coordination, exact identity, empty prices, quota pauses and outage preservation. Deployment and a production request followed by a completed alarm are still required to confirm the feature is operating with the configured production token.
