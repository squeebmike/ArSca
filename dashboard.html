🏷️ PRINT LABELS

Sheet mode prints multiple labels per page with dashed cut lines -- works on plain paper or Avery-style sheets. Roll mode prints exactly one label per "page" sized to match a direct-thermal roll printer (no margins, no cut lines needed). Toploader-wrap layout is meant for roll labels: stick the left half to the front over the toploader's edge, fold at the dashed line, and the logo + QR code half lands on the back (the toploader-wrap back face always uses a QR code, regardless of the barcode style picked above -- it reads more reliably at that size than a linear barcode). Barcode value uses UPC, then SKU, then falls back to the item's internal ID -- that fallback ID is long, which is where a linear barcode can get too dense to scan at small label sizes; switch to QR code above if standard-layout scans are failing. Prices on printed labels always round to whole dollars.
Printing from a phone to a Bluetooth thermal label printer (Rollo, MUNBYN, etc.)? Those printer apps usually can't receive a job from PRINT above -- the phone's system print dialog only offers full page sizes (Letter, A4...) with no way to fit a small label, so the label prints microscopic. Use DOWNLOAD PNGs instead: it saves one correctly-sized image per label straight to your phone, ready to import into your printer's app.
